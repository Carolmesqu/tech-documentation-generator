# 📄 Gerador de Documentação Técnica / Technical Documentation Generator

Um gerador de documentações técnicas bilingue (PT-BR / EN) que roda diretamente no navegador. Ideal para padronizar processos, mapear tabelas de banco de dados, permissões e passos operacionais, exportando o resultado em um PDF limpo, moderno e otimizado.

## 🚀 Funcionalidades / Features

- **Suporte Bilingue:** Alternância dinâmica de idioma (Português / Inglês) para a interface e para o documento final.
- **Exportação Inteligente:** Geração de PDF via `html2pdf.js` corrigindo automaticamente quebras de página e scrolls.
- **Design Clean:** Interface responsiva construída com Bootstrap e tipografia premium (*Inter*).

## 🛠️ Tecnologias Utilizadas / Tech Stack

- **HTML5**
- **CSS3** (Bootstrap 5 & Google Fonts)
- **JavaScript** (Vanila / ES6)
- **html2pdf.js** (Biblioteca para conversão de HTML para PDF)

## 📂 Como utilizar / How to use

Não requer instalação ou servidor backend!
1. Faça o download ou clone este repositório.
2. Abra o arquivo `index.html` em qualquer navegador moderno.
3. Escolha o idioma desejado, preencha os campos técnicos e clique em **Exportar Documento PDF**.
